# Network Security Lab

Laboratorio de redes y ciberseguridad con segmentación, detección de intrusos
y monitoreo, construido desde cero en un entorno aislado.

> **Aviso:** todo este laboratorio se ejecuta en un entorno virtual aislado
> con fines educativos. Las máquinas vulnerables nunca se exponen a redes reales.

## Objetivo

Diseñar, implementar, atacar y defender una red segmentada, documentando cada
fase con evidencia reproducible.

## Estado del proyecto

| Fase | Descripción | Estado |
|------|-------------|--------|
| 00 | Lab base: Kali Linux + Metasploitable 2 | Terminado |
| 01 | Diseño de red en Cisco Packet Tracer (VLANs, ACLs) | Terminado |
| 02 | Segmentación con pfSense | Pendiente |
| 03 | Análisis de tráfico con Wireshark | Pendiente |
| 04 | IDS con Suricata | Pendiente |
| 05 | VPN con WireGuard | Pendiente |
| 06 | Monitoreo con Wazuh | Pendiente |

## Tecnologías

VirtualBox · Kali Linux · Metasploitable 2 · pfSense · Cisco Packet Tracer ·
Wireshark · Nmap · Suricata · WireGuard · Wazuh

## Skills que demuestra

Segmentación de redes · Reglas de firewall · Escaneo y análisis de
vulnerabilidades · Análisis de tráfico · Detección de intrusos · Documentación técnica

## Estructura

- `docs/`: documentación por fase
- `evidence/`: capturas y archivos de salida
- `diagrams/`: diagramas de red
- `configs/`: configuraciones sanitizadas
